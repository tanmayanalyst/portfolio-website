# Tanmay Thakur — Developer & Automation Engineer

> Modern, immersive personal portfolio website crafted with an **Obsidian Crimson** dark theme, interactive canvas particle system, 3D tilt micro-interactions, responsive terminal runner, and spatial sound engine.

---

## ⚡ Features & Visual Experience

- **Obsidian Crimson Theme:** Deep obsidian blacks (`#040407`), radiant crimson neon accents (`#e6193c`), and clean crisp white typography (`#f4f4f7`).
- **Interactive Particle Canvas:** Ambient connected particle mesh rendered in real-time on `<canvas>` responding dynamically to mouse movement.
- **3D Tilt Cards:** Multi-axis perspective hover physics with dynamic radial spotlights across Project and Experience cards.
- **Live Interactive Terminal:** Fully interactive command-runner simulation showcasing active autonomous AI projects like *AutoNews AI Agent* and *PromptPilot*.
- **Interactive Spatial Sound Engine:** Web Audio API sound synthesizer with mute/unmute toggle for tactile feedback on clicks and navigation.
- **Dynamic Floating Ambient Photos:** Smooth parallax floating photography layers accentuating section transitions.
- **100% Responsive Design:** Pixel-perfect layout tailored for Desktop (1440px+), Tablet/Laptop (1024px, 768px), and Mobile (390px).

---

## 🛠️ Tech Stack

- **Frontend:** Vanilla HTML5, Modern CSS3 (Grid, Flexbox, Custom Properties, Glassmorphism), Vanilla JavaScript (ES6+)
- **Server:** Ultra-lightweight Node.js HTTP server (`server.mjs`) with zero heavy framework overhead
- **Typography:** Google Fonts (*Sora*, *Inter*, *JetBrains Mono*, *Caveat*)
- **Icons:** SVG vector iconography

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/tanmayanalyst/portfolio-website.git
cd portfolio-website
```

### 2. Run locally
```bash
# Option A: With Node.js
npm start

# Option B: Any static file server
# Or open index.html directly in any modern browser!
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
